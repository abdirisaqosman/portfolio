Pulse

🚧 building

Self-hosted uptime monitor

Register HTTP endpoints; a decoupled background worker pings them on a schedule and a live dashboard shows status, uptime %, and latency over time. The project is the DevOps artifact — Fastify API, Postgres, a separate worker process, then Docker → Kubernetes (kind) → Cloudflare Tunnel, with CI that deploys to an ephemeral cluster and smoke-tests it.

Local-business lead finder

Search a category + location, scrape matching businesses through pluggable providers — synthetic data, the official Google Places API, or a Playwright browser scrape — de-duplicate them globally, then browse, filter, and export from a dashboard. A real data-collection pipeline: scrapers → background jobs → Postgres → REST API → React, fully containerized.
